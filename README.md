AI Powered Personalized Learning Platform
The AI-Powered Personalized Learning Platform generates customized learning paths for any topic using Google’s Gemini API. It provides structured daily study plans, recommended resources, and progress tracking. Built with Flask and React, it adapts to each user’s goals, time, and skill level for efficient learning.
Installation
1. Run the following commands: npm install cd backend pip install -r requirements.txt
2. Create a .env file in the backend folder and add your Gemini API key: GEMINI_API_KEY=your_api_key
3. To start the backend: npm run backend
4. To start the frontend: npm start
Features
* AI-generated personalized learning paths
* Daily study plans with YouTube and web resources
* User progress tracking and visualization
* Supports multiple languages and topics
* Flask backend and React frontend integration
Usage Enter any topic and the number of weeks you want to learn it in. The platform will generate a detailed, day-by-day learning roadmap with curated resources.
Tech Stack Frontend: React.js, JavaScript, HTML, CSS Backend: Python (Flask) AI Integration: Google Gemini API
License This project is open-source and free to use for educational purposes.
